# Portfolio de Rafael

Web personal creada para la práctica de control de versiones de DAW2.
Incluye una presentación y enlaces a mis proyectos.

## Tecnologías

- HTML5 para la estructura.
- CSS3 para los estilos.
- SVG para el avatar.
- Git y GitHub para el control de versiones.
- GitHub Pages para la publicación.

https://rafael1570.github.io

## Comprobación local

Abrir index.html en VS Code y seleccionar Open with Live Server.
